# Synent Internship task one - Personal Portfolio Website

## 📌 Project Overview

This project is a Personal Portfolio Website developed as part of the **Synent Technologies Web Development & Designing Internship Program**.

The website showcases my profile, technical skills, projects, and contact information through a modern, responsive, and user-friendly interface.

---

## 🚀 Features

- Responsive Design
- Modern User Interface
- Hero Section
- About Me Section
- Skills Section
- Projects Section
- Contact Section
- Mobile-Friendly Layout
- Smooth Navigation
- Social Media Links

---

## ⚙️ Installation & Setup

### Navigate to Project Directory

```bash
cd synent-task1-portfolio-krushna
```

### Install Dependencies

```bash
npm install
```

### Run Development Server

```bash
npm run dev
```

### Build for Production

```bash
npm run build
```
